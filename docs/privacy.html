Privacy and security notes.

Chat LLM is intentionally static. That makes deployment simple, but it also means browser-side API calls have important constraints.

API key storage

The OpenAI API key is memory-only by default. If you enable the tab-session option, it is stored in sessionStorage until the tab session ends. In both modes, requests are sent directly from your browser to OpenAI.

Browser state

Chat history, settings, and model choices are stored in local browser storage. Oversized artifacts are kept out of persisted storage, and Privacy reset clears keys, chats, settings, and cached account models.

Production use

This milestone is intentionally pure GitHub Pages. It is suitable for BYOK personal or trusted-team distribution, not for shared-key SaaS use. A static page cannot hide API keys from the browser runtime.

Content safety

Assistant output is rendered through the app markdown sanitizer. The chat app uses vendored scripts and styles with a restrictive content security policy that keeps script and style loading on the same origin.
