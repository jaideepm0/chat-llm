Setup Chat LLM.

Run the app locally or publish it on GitHub Pages without a build step or server runtime.

Quick start

  1. Open the app workspace.
  2. Press Send once or open Settings from the left rail.
  3. Paste an OpenAI API key. It stays in memory by default; optionally remember it for this tab session.
  4. Choose a model, type a message, and send.

GitHub Pages

Publish the repository root with GitHub Pages. The app uses static HTML, CSS, JavaScript modules, and vendored browser assets only.

The app page is /app.html. The homepage and docs pages are crawlable static pages for discoverability.

API key

For personal or trusted-team use, paste a key in Settings. This app is BYOK: every request goes directly from the browser to OpenAI, and the app never ships a shared key.

Local development

python3 -m http.server 8092
open http://127.0.0.1:8092/

Localhost API base URLs are allowed only while running locally. Run npm run verify before publishing changes.
