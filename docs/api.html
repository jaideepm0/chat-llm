API support in Chat LLM.

The app is built around POST /v1/responses and keeps current model, tool, and multimodal controls visible in a dedicated run inspector.

Models

The default model is gpt-5.5. The model picker includes GPT-5.4, GPT-5, Codex, o-series reasoning, audio, search, and computer-use model IDs where relevant. Requests use the Responses API only.

Web search

Enable the Responses API web_search tool, configure allowed or blocked domains, choose context size, set external access, and request source inclusion for citations.

File search

File search accepts vector store IDs and a max-results cap. This static app does not upload or index files by itself; use vector stores that already exist in your OpenAI project.

Image generation

The image generation tool can be enabled from the Tools inspector with action, size, quality, and partial image frame controls. Generated image artifacts render inside assistant messages, and oversized base64 payloads are not persisted.

Attachments

The Sources inspector accepts image URLs and file URLs for the next turn. Those values are converted to Responses API input_image and input_file content items.

Request preview

The API inspector shows a sanitized request payload before sending. It helps verify model, reasoning, tool choice, prompt cache, service tier, and attachment state. A static preflight blocks unsupported modes and asks for confirmation before expensive or stateful options.
